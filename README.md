# User Management Dashboard

A responsive User Management Dashboard built with HTML, Tailwind CSS, and JavaScript (ES6+), as part of MERN stack preparation.

## Features
- Add, edit, search, and delete users
- Data persistence using LocalStorage
- Fetches initial user data from the JSONPlaceholder API using async/await
- Loading and error states
- Course filter (All, MERN, React, Node.js, C++)
- Form validation (required fields + email format)
- Fully responsive design (mobile, tablet, desktop) using Tailwind CSS

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
- JavaScript (ES6+)
- Fetch API
- LocalStorage

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. No build steps or installation required.

## API Used
[JSONPlaceholder Users API](https://jsonplaceholder.typicode.com/users)
